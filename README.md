## Propulse Livestream Overlay
This repo is an old edition of the livestream overlay used during Propulse's launch streams. Sadly the up-to-date source code is behind closed walls.

If you want to check out how it looks for yourself, consider taking a look at the [launch video of Propulse's Heimdall rocket!](https://www.youtube.com/watch?v=f1tRKNCVl8Y)
